# Distributed Ledger Applications

## move-to-json

This app offers a command line workflow for compiling Move contracts and preparing deployment-ready JSON data for IOTA networks. It is designed for teams that want a repeatable path from source code to deployable artifacts, with support for environment-driven operation across test and production targets. For wider ecosystem documentation, see [IOTA developer guides](https://docs.iota.org/developer).
